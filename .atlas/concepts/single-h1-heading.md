# Use A Single H1 Heading

A Markdown document should use one H1 heading as its title, with all subsequent headings at H2 or deeper.[^s1]

[^s1]: [[.atlas/sources/google-markdown-style-guide]] Quoted span "Use one H1 heading as the title of your document. Subsequent headings should be".
